# Dinkabalen 2026 — Player Portal

**Public, read-only presentation repository** for Dinkabalen Pickleball Tournament 2026.

The private administrative source lives in `qourts/admin_dinkabalen`. This repository must **never** contain the operator-enabled master, editable score records, backup data, or administrative functionality.

## Publication policy
- Only publish an independently verified, read-only Player Portal artifact from the authoritative Admin results snapshot.
- Confirm event identity, schedule and teams, results, standings, playoff participants, and publication revision before release.
- A generated file does not update phones automatically. The approved artifact must be committed/deployed; visitors may need to reload to see the new version.
- Do not publish demo/sample scores as tournament results.
- Reject unresolved or contradictory playoff data.

## Current status
**Repository initialized for separation only.** No production Player Portal or GitHub Pages deployment has been made by this commit.
